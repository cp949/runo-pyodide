# 양성 대조(DELTA-06)

`session-reset-check.mjs`가 실제로 무언가를 검증하는지 확인하려고 일부러 깨뜨린 뒤 원복했다. 둘 다
원복 후 `git status --short`가 비어 있음을 확인했다.

## 1. 안내 문구 변조 → `reset` 절 실패

`packages/pyodide-repl/src/index.ts`의 `RESET_NOTICE`에 `MUTATED ` 접두어를 넣음.

```
ONLY=reset node .../session-reset-check.mjs http://localhost:5173
```

결과: `reset: 리셋 버튼 → 안내 줄·배너·프롬프트 순서(마지막 4행)` FAIL(확인 스크립트의 상수와 실제
안내 줄이 달라 `same()` 비교가 깨짐). 원복 뒤 같은 절 재실행 → 전부 PASS.

## 2. 재시작 버튼이 `reset()`을 안 부르게 변조 → `crash` 절 실패

`apps/demo/src/ReplView.tsx`의 `restart` 버튼 `onClick`에서 `replRef.current?.reset()` 호출을 제거(
`setCrashMessage(null)`만 남김).

```
ONLY=crash node .../session-reset-check.mjs http://localhost:5173
```

결과: `crash: 재시작 버튼 → 배너 → 1+1 → 2` FAIL(`resetAndWait("restart")`가 `loading` 상태 전이를
기다리다 시간 초과 — 버튼을 눌러도 세션이 안 바뀌니 `status`가 `crashed`에 머문다). 원복 뒤 같은 절
재실행 → 전부 PASS.
