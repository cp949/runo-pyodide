# DELTA-04 브라우저 변이 4건(양성 대조)

방식: 소스 변조 → dev(vite) HMR 반영 대기(1~3초) → `ONLY=<절>`로 재실행 → 실패 확인 → `cp`로 원복 →
`git status --short`로 원복 확인 → 관련 vitest로 회귀 재확인.

## M1 복합문 뒤 `""` push 제거

- 파일: `packages/pyodide-repl/src/worker/submission-runner.ts`
- 변경: `runChunk`의 `return result.kind === "incomplete" ? runOne("", { echo }) : result;` →
  `return result;`
- 실행: `ONLY=paste`
- 결과: FAIL — `paste: def add… 붙여넣기 Enter 1회 → 3, SyntaxError 없음` 등 복합문 셀 3개가 전부
  `IndentationError`/`SyntaxError`로 실패(블록이 빈 줄로 안 닫혀 다음 줄이 블록 안으로 들어가 버림).
  `1\n2\n3`(단순 문장만)·주석·한 줄 셀은 영향 없이 PASS.

## M2 `echo = 마지막 청크`를 항상 `true`로

- 파일: `packages/pyodide-repl/src/worker/submission-runner.ts`
- 변경: `const result = await runChunk(chunk, index === chunks.length - 1);` →
  `const result = await runChunk(chunk, true);`
- 실행: `ONLY=paste`
- 결과: FAIL — `paste: 1\n2\n3은 마지막 값만 에코한다(S03)`만 실패(마지막 5행이
  `["3","1","2","3",">>>"]`로, `1`·`2`도 값 에코됨). 나머지 7개 셀은 PASS(마지막 문장만 있거나
  echo 없는 문장이라 영향 없음).

## M3 벤더 탭 승격 제거

- 파일: `packages/xterm-readline/src/readline.ts`
- 변경: `readPaste`의 `UnsupportedControlChar`+`data===["\t"]` → `Text(["\t"])` 승격 분기 삭제.
- 실행: 먼저 `pnpm --filter @cp949/runo-xterm-readline test` → DELTA-01 시험
  `붙여넣은 탭을 버퍼에 보존한다` RED(1건, 93건 GREEN). 이어서 `ONLY=tab` 브라우저 확인.
- 결과: FAIL — `tab` 절이 `IndentationError: expected an indented block after function definition
on line 1`로 실패(탭이 사라져 `def f():` 다음 줄이 들여쓰기 없는 `return 1`이 됨).

## M4 2차 `compile` 제거

- 파일: `packages/pyodide-repl/src/worker/multiline.py`
- 변경: `split_paste`에서 `tree = _parse(source, flags)` 다음의
  `compile(tree, "<console>", "exec", flags, True)` 줄 삭제.
- 실행: `ONLY=parse`
- 결과: FAIL — `parse: 함수 밖 return은 2차 compile 오류로 무실행이다`가 실패
  (`print(1)`이 실제로 실행돼 단독 `"1"` 행이 남음). `parse` 절의 다른 셀(S07)은 영향 없이 PASS.
  - 1차 시도에서 이 셀의 검사(`t[idx+1] === "1"`만 확인)가 너무 좁아 변이를 놓쳤다(입력 에코
    `print(1)`/`return 2` 두 줄이 먼저 오고 그 *다음*에 `"1"`이 오는 배치를 안 봄). `t.includes("1")`
    로 넓혀 잡았다 — `multiline-check.mjs`에 반영, "## 결정" 참고.

## 원복 확인

4건 모두 원복 뒤 `git status --short packages/`가 빈 출력이었고, 관련 vitest(
`@cp949/runo-xterm-readline test`, `@cp949/runo-pyodide-repl` 관련 스위트)와 전체
`multiline-check.mjs`(dev 8절 + preview 3절)를 재실행해 전부 GREEN으로 되돌아온 것을 확인했다
(`verify/results/dev.json`·`preview.json`).
