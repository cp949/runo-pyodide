## 대조 1: `decideKey`의 `hasSelection` 가드 제거

- 변경: `packages/pyodide-terminal/src/selection-copy.ts`의 `decideKey` 조건에서
  `hasSelection` 항을 지웠다(`key.key.toLowerCase() === "c" && hasSelection` →
  `key.key.toLowerCase() === "c"`). 결과: 선택 유무와 무관하게 Ctrl+C가 항상 `"copy"`로
  판정된다.
- 재시작 후 실행: `ONLY=초기,S05 node verify/selection-copy-check.mjs http://localhost:5173`
- 실패한 셀: **S05**(선택 없이 Ctrl+C → `KeyboardInterrupt` + 새 프롬프트, RD-007 회귀).
- 실제 출력:
  ```
  FAIL  S05 선택 없이 Ctrl+C → KeyboardInterrupt + 새 프롬프트(회귀)  — 시간 초과: 프롬프트 ">>>"
        — 화면 끝 [">>> while True: pass","..."]
  ```
- 원인: 선택이 없어도 `decideKey`가 `"copy"`를 돌려주므로 `onKeyEvent`가 `preventDefault()` +
  `copy()`(빈 문자열 → 내부에서 조용히 무시) + `return true`로 끝난다. 벤더 `handleKeyEvent`가
  `true`를 받아 xterm 처리를 건너뛰어 ETX가 `onData`로 전혀 흐르지 않는다 — SIGINT가 나가지
  않아 `while True: pass`가 15초(대기 상한) 안에 끊기지 않는다.
- 원복: `terminal.clearSelection();`이 아니라 조건 자체를 되돌림 — `git diff`로 무변경 확인.

## 대조 2: `onKeyEvent` 복사 경로의 `clearSelection()` 제거

- 변경: 같은 파일의 `onKeyEvent`에서 `copy(); terminal.clearSelection(); return true;`의
  `terminal.clearSelection();` 줄을 지웠다.
- 재시작 후 실행: `ONLY=초기,S02 node verify/selection-copy-check.mjs http://localhost:5173`
- 실패한 셀: **S02**(실행 중 배너 행 드래그 → Ctrl+C(복사) → 300ms → Ctrl+C(중단)) — 계획서가
  예상한 "두 번째 Ctrl+C 셀"에 해당하는 검사(첫 Ctrl+C 뒤 선택 해제 확인)에서 실패했다. S02는
  체크리스트 한 행 전체를 한 셀로 묶어 검증하므로, 실패 지점은 "선택 해제" 단언이지만 원인은
  두 번째 Ctrl+C가 의도대로 동작하지 않게 되는 바로 그 결함이다(아래 "추가 확인" 참고).
- 실제 출력:
  ```
  FAIL  S02 실행 중 배너 행 드래그 → Ctrl+C(복사) → 300ms → Ctrl+C(중단)
        — 선택이 해제되지 않음(.xterm-selection 자식 2)
  ```
- 추가 확인(자동 셀에는 없는 수동 확인, 근본 원인 실측): 임시 스크립트로 1차 Ctrl+C 뒤
  `.xterm-selection` 단언을 건너뛰고 2차 Ctrl+C까지 계속 진행하면, `waitPrompt(">>>", 15000)`이
  타임아웃(15초 안에 프롬프트 복귀 없음) — `clearSelection()`이 없어 `terminal.hasSelection()`이
  계속 참으로 남고, 2차 Ctrl+C도 `decideKey`가 다시 `"copy"`로 판정해(이미 복사된 것과 같은
  텍스트를 다시 복사) SIGINT가 나가지 않는다. `while True: pass`가 끊기지 않는다.
- 원인: `clearSelection()`을 부르지 않으면 Ctrl+C 복사 뒤에도 내부 선택 상태가 남아, 다음
  Ctrl+C가 인터럽트·취소로 이어지지 않고 계속 복사로만 판정된다(RD-017 확정 2가 요구하는
  정확한 이유).
- 원복: `terminal.clearSelection();` 줄 복원 — `git diff`로 무변경 확인.
