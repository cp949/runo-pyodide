# @cp949/runo-xterm-readline 원본 대비 변경 이력

[strtok/xterm-readline](https://github.com/strtok/xterm-readline) 1.2.2(커밋 `8869f17542bed618d8f389fea46c000089a8d9ad`) 벤더링 이후 소스에 직접 넣은 변경을 시간순으로 기록한다. 요약은 `README.md` "원본 대비 변경"을 본다.

`highlight`·`keymap`·`line`·`vterm`은 원본과 바이트 동일하다. `tty`는 RD-022a에서 `eraseLine`이 추가되어 원본과 다르다.
