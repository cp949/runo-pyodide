# TRP-081 옵션 기본값·전달 줄을 지워도 소비자 시험 전체가 통과할 수 있다

- 상태: ACTIVE
- 적용 조건: 소비자(`createRepl`·`createTerminalRunner`)의 옵션 기본값 정규화·전달 줄(`copyOnSelect`·`onCopy` 등)을 다른 module로 옮기거나 새 옵션을 소비자에서 하위 module로 넘길 때.

## 오해하기 쉬운 신호

- 소비자 시험이 전부 통과한다(repl 1118건). 전달 줄을 지우는 변이도 0건 실패로 통과했고, 전환 전 코드에서 정규화 줄을 지워도 같았다. 통과 로그만 보면 동작 보존이 확인된 것처럼 읽힌다.
- 시험은 기본값 경로(옵션 미지정)만 지나가면 옵션을 넘기는 줄과 넘기지 않는 줄을 구분하지 못한다.

## 원인

- 옵션이 결과에 미치는 영향(`copyOnSelect: false`면 드래그 복사가 없다, `onCopy`가 복사 결과를 받는다)은 관찰 가능한데도 기존 시험이 옵션 값을 바꿔 호출하는 경우를 세지 않았다. 리팩터링이 만든 회귀가 아니라 전환 전부터 있던 공백이다.

## 탐지/회피

- 옮기는 옵션마다 전달 줄 삭제 변이를 돌려 시험이 1건 이상 실패하는지 본다. 살아남으면 옵션에 기본값과 다른 값을 넣어 결과를 비교하는 시험을 더한다. 이 저장소에서는 `packages/pyodide-repl/test/create-repl/selection-copy.test.ts`의 `copyOnSelect`·`onCopy` 전달 시험 2건이 그 형태다.
- 변이 스크립트를 부르는 셸 명령에서 `pkill -f <스크립트 이름>`은 그 명령줄 자신도 종료시킨다(종료 코드 144).
